GitLabRunner

Получил Registration Token из GitLab:
Открыл http://localhost:8080
Логин: root, Пароль: admin12345
Admin → Overview → Runners
Скопируй "Registration token"
Регистрация ранера
docker exec -it gitlab-runner-http gitlab-runner register \
  --non-interactive \
  --url "http://gitlab:80" \
  --registration-token "ВАШ_TOKEN_ЗДЕСЬ" \
  --executor "docker" \
  --docker-image "docker:latest" \
  --docker-volumes "/var/run/docker.sock:/var/run/docker.sock" \
  --description "local-docker-runner" \
  --tag-list "docker,local" \
  --run-untagged="true"
--- Защищенный формат
генерируется ssl сертификат (уже лежит в ssl папке)
(если есть openssl)
openssl req -x509 -nodes -days 365 -newkey rsa:2048 `
  -keyout gitlab.key `
  -out gitlab.crt `
  -subj "/C=RU/ST=Moscow/L=Moscow/O=Company/CN=gitlab.local"

(если нет)
@'
-----BEGIN DEMO PRIVATE KEY-----
# Это демо-ключ для GitLab HTTPS
# В реальном проекте: openssl genrsa -out gitlab.key 2048
-----END DEMO PRIVATE KEY-----
'@ | Out-File gitlab.key -Encoding ASCII

@'
-----BEGIN DEMO CERTIFICATE-----
# Это демо-сертификат для GitLab HTTPS
# В реальном проекте: openssl req -new -x509 -key gitlab.key -out gitlab.crt
-----END DEMO CERTIFICATE-----
'@ | Out-File gitlab.crt -Encoding ASCII
